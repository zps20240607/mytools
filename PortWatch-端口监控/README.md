# PortWatch 2.0 · 端口监控台（Windows 版）

对标 GitHub 开源项目 **[laogou717/local-ops](https://github.com/laogou717/local-ops)**（macOS 本地总控台，MIT 许可）的 Windows 1:1 适配版：同一套前端 UI 与操作逻辑，进程/端口采集层改用 Windows 原生实现。

- **零依赖**：后端只用 Python 3 标准库，前端是无构建、无 CDN 的原生 HTML/CSS/JS。
- **只绑定 127.0.0.1**，仅服务当前用户，**不要**通过端口映射/反向代理对外暴露。

## 快速开始

1. 双击 `启动控制台.bat`：后台静默启动（pythonw），自动打开浏览器，端口 9600-9609。
2. 双击 `停止控制台.bat`：结束服务。
3. 命令行方式：`python server.py`（前台调试）、`python server.py --no-browser`、`python server.py --preferred-port 9603`。

> 手动启动时控制台窗口不要关闭；用 `停止控制台.bat` 或页面左下角的停止按钮正常退出。

## 功能（对齐 local-ops）

- **启动台**：应用卡片，一键 启动 / 停止 / 重启 / 看日志 / 编辑 / 删除 / 附加端口，支持拖拽排序；运行中卡片实时显示端口与健康状态。
- **服务监控**：三区分列「我的服务 / 后台进程 / 已隐藏」，实时 CPU%、内存、命令行、端口；支持 关注关键字、忽略隐藏、一键打开服务页面。
- **端口发现**：会话内自动发现新监听端口并提醒，可「加入启动台」「忽略」，刷新后按真实监听状态重建基线。
- **日志中心**：每个应用独立日志文件，自动跟随、清空、下载、复制；`Ctrl+J` 快捷打开。
- **命令面板**：`Ctrl+K` 搜索应用、端口、命令与操作。
- **控制台自管理**：页面内可直接 重启 / 停止 PortWatch 本身（重启后自动重连）。
- **主题切换**：内置 ops 等主题，右上角一键切换并持久保存。

## 与 local-ops 的差异（Windows 适配）

| 维度 | local-ops（macOS） | PortWatch（Windows） |
| --- | --- | --- |
| 启动方式 | 总控台.app | `启动控制台.bat` |
| 进程/端口/CPU/内存采集 | ps / lsof / top 等系统命令 | `ctypes` 直接调用 `kernel32` / `ntdll` / `iphlpapi` / `ws2_32`，不冒 PowerShell 窗口 |
| 命令解析 | shlex | 自实现引号感知分词，兼容 `python -c "..."` |
| 端口占用检查 | — | 不设 `SO_REUSEADDR`，占用检测真实可靠 |
| 停止任务 | 信号终止 | 进程树终止（含子进程）+ 可配置「停止时额外结束」正则 |
| 服务端口归属 | 单进程 | 根进程 + 后代进程树归属，兼容 bat/cmd 包装后的真实监听者 |
| 快捷键 | ⌘K / ⌘J | Ctrl+K / Ctrl+J |
| 路径 | /Users/... | C:\Users\... |

## 数据位置

- 配置：`data\config.json`（应用列表、隐藏端口、主题；旧版 `tasks[]` 配置会在首次启动时自动迁移）
- 应用日志：`data\logs\*.log`；控制台日志：`data\logs\console.log`
- 运行标记：`data\server.pid`（停止脚本依赖它）
- 图标缓存：`data\icons\`

## 安全边界

- 服务只监听 `127.0.0.1` 并校验 Host 头；写操作需要 HttpOnly 会话 Cookie，防止本机网页跨站调用。
- 它能以当前用户权限执行你保存的命令，只添加你检查过的脚本。
- 应用以隐藏窗口方式运行（CREATE_NO_WINDOW），输出写入日志文件。
